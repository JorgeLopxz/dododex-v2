# 🦖 DODODEX V2

Companion app personal para **ARK: Survival Ascended / Evolved** — lo mejor de Dododex y Wikily, más lo que ninguna tiene: **inspector de stats post-tame** y biblioteca de tus dinos.

## Features clave (objetivo)

- ⭐ **Inspector post-tame**: introduce los stats de tu dino ya domado y descubre cuántos puntos cayeron en cada stat (lo que Dododex no puede hacer).
- 🦕 **Mis Dinos**: biblioteca local de tus tames con desglose de puntos, filtrable y ordenable.
- 🧮 Calculadora de tameo (comida, narcóticos, torpor, efectividad).
- 🧬 Árbol genealógico + tracker de mutaciones con el modelo ASA correcto.
- ⏰ Scheduler de imprint y cría.
- 🎨 Diseño "Ámbar y hueso": temática dino sobria, dark-first, accesible (WCAG 2.2 AA, paleta apta para daltonismo).
- 📱 PWA offline, local-first, sin cuentas ni anuncios.
